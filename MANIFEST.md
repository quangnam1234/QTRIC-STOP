# Deliverables

- `src/qtrc_stop/`: complete Python implementation.
- `configs/`: smoke, pilot and full experiment profiles.
- `scripts/`: Linux/macOS/WSL Bash and Windows PowerShell launchers.
- `tests/`: unit tests for feature extraction, taxonomy, stopping and checkpoints.
- `guide/QTRC_Stop_Huong_dan_IEEE1cot.tex`: Vietnamese IEEE one-column guide.
- `guide/QTRC_Stop_Huong_dan_IEEE1cot.pdf`: compiled and visually verified guide.
- `verification/`: smoke CP0-CP8 and full-data CP0-CP3 validation summaries.

The Polliradar dataset is not redistributed. Pass the supplied ZIP path through `--dataset` or the run scripts.
